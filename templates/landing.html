How it works

Three steps to cleaner docs.

1

Label your PR

Add a docs, documentation, or inkguard label to any pull request. InkGuard only runs when you ask it to — no noise on code-only PRs.

2

InkGuard reviews

The bot scans every changed .md, .txt, and .rst file. Code blocks, CLI flags, API paths, and URLs are automatically skipped.

3

Approve or request changes

Clean docs get a ✅ Docs approved review. Issues get a detailed comment with exact line, suggested fix, and the rule that was broken.

Features

Everything a documentation team needs.

🏷️

Label-triggered

Only activates on PRs with doc-related labels. Fully configurable via IG_LABELS.

🧠

Technical-doc aware

Skips fenced code blocks, inline code, CLI flags (--flag), API paths (/v1/endpoint), and URLs automatically.

✅

Docs approved flow

High-scoring PRs get a formal GitHub "Approve" review. Low-scoring PRs get "Request changes" — just like a human reviewer.

📊

Scored & graded

Every file gets a 0–100 score and an A–D grade. Track documentation quality over time in the dashboard.

🔇

No comment spam

InkGuard updates its own comment on every push — one clean comment per PR, always current.

⚡

Zero config install

Copy one workflow file. No API keys, no external accounts. GITHUB_TOKEN is injected automatically.

🌐

REST API

Four endpoints: /check, /batch, /upload, /export. Pipe it into any tool.

📈

Dashboard

GitHub OAuth login. See scan history, average scores, and per-file trends for your organisation.

Get started in 2 minutes

Copy. Paste. Done.

.github/workflows/inkguard.yml
name: InkGuard
on:
  pull_request:
    types: [opened, synchronize, labeled]
    paths: ["**.md", "**.txt", "**.rst"]

permissions:
  pull-requests: write
  contents: read

jobs:
  inkguard:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install flask
      - name: Run InkGuard
        env:
          GITHUB_TOKEN: ${% raw %}{{{% endraw %} secrets.GITHUB_TOKEN }}
          IG_SCORE_THRESHOLD: "80"
        run: python bot/inkguard_bot.py
