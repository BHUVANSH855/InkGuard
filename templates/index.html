REST API Reference

GrammarLens exposes a simple HTTP API. Integrate it into any pipeline.

POST
/check

Analyse a single block of text.

curl -X POST /check \
  -H "Content-Type: application/json" \
  -d '{"text": "i is going to the store"}'
Returns: corrected, errors[], score, grade, word_count
POST
/batch

Analyse up to 50 documents in one call. Perfect for CI pipelines.

curl -X POST /batch \
  -H "Content-Type: application/json" \
  -d '{"documents":[{"id":"readme","text":"..."}]}'
Returns: results[], summary{total_errors, avg_score}
POST
/upload

Upload a plain-text or Markdown file directly.

curl -X POST /upload \
  -F "file=@README.md"
Returns: same as /check + filename
POST
/export

Download a full JSON report for a given text.

curl -X POST /export \
  -H "Content-Type: application/json" \
  -d '{"text":"..."}' \
  -o report.json
Returns: report.json download

GitHub Actions Example

- name: GrammarLens check
  run: |
    curl -sf -X POST http://localhost:5000/batch \
      -H "Content-Type: application/json" \
      -d "$(jq -n --arg t "$(cat README.md)" \
           '{documents:[{id:"readme",text:$t}]}')" \
    | jq '.summary'
