How it works

Three steps. Zero friction.

🏷️

Label your PR

Add docs, documentation, or inkguard to any pull request. InkGuard only activates on labelled PRs — no noise on code-only changes.

🧠

InkGuard analyses

Every changed .md, .txt, and .rst file is scanned. Fenced code blocks, CLI flags (--flag), API paths, and URLs are automatically skipped.

✅

Approve or request changes

Clean docs get a formal GitHub Approve review with a score. Errors get a Request changes review with an issues table, exact suggestion, and the rule broken.

Features

What makes InkGuard different.

Label-triggered only

Runs only when a PR carries a doc-related label. Fully configurable. Zero interference with code reviews.

Technical-doc aware

Skips fenced code, inline code, CLI flags, API paths, URLs, frontmatter, and markdown tables. No false positives on technical content.

Approve or request changes

Posts a formal GitHub review — not just a comment. High scores get approved. Low scores block the merge until fixed.

Scored and graded

Every file gets a 0–100 score and an A–D grade. Per-file breakdown, total errors, and word count on every review.

No comment spam

InkGuard updates its own comment on every commit push. One clean comment per PR, always showing the latest state.

Zero config

Copy one workflow file. No API keys, no external accounts. GITHUB_TOKEN is injected automatically by GitHub Actions.

REST API included

Four endpoints: /check, /batch, /upload, /export. Pipe InkGuard into any CI tool or documentation pipeline.

Dashboard

GitHub OAuth login. View scan history, score trends, and per-file results for your whole organisation in one place.

Get started

Up and running in 2 minutes.

1

Copy the workflow

Add .github/workflows/inkguard.yml to your repository. That's the only file you need.

2

Label a PR

Open any pull request that touches docs. Add the docs or documentation label.

3

InkGuard reviews

The bot posts its review within seconds. Clean docs get approved. Issues get a detailed comment.

.github/workflows/inkguard.yml 
name: InkGuard
 
on:
  pull_request:
    types: [opened, synchronize, labeled]
    paths:
      - "**.md"
      - "**.txt"
      - "**.rst"
 
permissions:
  pull-requests: write
  contents: read
 
jobs:
  inkguard:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install flask
      - name: Run InkGuard
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          IG_SCORE_THRESHOLD: "80"
          IG_LABELS: "docs,documentation,inkguard"
        run: python bot/inkguard_bot.py
